# Referências visuais fornecidas pelo usuário

As referências de agosto de 2026 definem a tela operacional de agendamentos como uma visão de alta densidade, com ações rápidas no topo e abas horizontais de status. As ações destacadas são **Agendamentos do Dia**, **De-Para Pendente**, **Recebimento sem Agendamento** e **Filtros**. O usuário confirmou que o Código SAP não deve aparecer no painel de filtros.

As abas de status devem incluir **Todos** como visão geral ativa, além de **Pendente**, **Agendado**, **Recebido**, **Concluído**, **Backlog** e **Rejeitado**, cada uma apta a exibir um contador. A tabela deve priorizar as colunas Status, Fornecedor, Destinatário, Nota Fiscal, Pedido, Data de Agendamento, ícones de ação e ação principal de agendar quando aplicável.

O painel de filtros solicitado deve conter dados úteis da operação: número da nota, nome do fornecedor, CNPJ do destinatário e período. O fluxo de filtro rápido de **Agendamentos do Dia** deve aplicar a data atual e apresentar automaticamente a lista correspondente.
